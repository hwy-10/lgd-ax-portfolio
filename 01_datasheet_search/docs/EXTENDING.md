# 프로젝트 부품 전체로 넓히는 절차

## 결론

검색기 하나로 프로젝트 BOM 의 어느 부품이든 질문할 수 있다. 다만 **답하는 것은 데이터시트를 등록한
부품뿐**이고, 나머지는 등록되지 않았다고 답한다. 근거가 없으면 답하지 않는다는 원칙을 부품 범위에도
그대로 적용한 것이다.

| 자동으로 되는 것 | 부품을 등록할 때 사람이 하는 것 |
|---|---|
| BOM 표 읽기, 회로 기호(U5)를 품번으로 바꾸기 | 데이터시트 PDF 와 리비전 확보 |
| 질문을 받으면 문서 고르기 | 주문 정보 표를 보고 변종 규칙 한 줄 쓰기 |
| 고른 문서 안에서 변종 게이트, 검증 게이트, 근거 충분성 | 평가 질문 3~5개와 정답 원문 표현 쓰기 |
| BOM 의 어느 부품이 어느 문서에 대응하는지 보고서 | 첫 측정에서 막힌 질문의 용어를 용어표에 보강 |
| 정답 사실이 원문에 실제로 있는지 검수 | |

## 구조

```
질문 ─▶ ⓪ 문서 선택 ─▶ (고른 문서 한 권) ① 품번 ② 변종 게이트 ③ BM25 ④ 검증 게이트 ⑤ 근거 충분성 ─▶ ⑥ 모델
         │
         ├─ 회로 기호면 BOM 으로 품번을 찾는다      U5 → LMR33630ADDAR → 변종 LMR33630A
         ├─ 두 부품 이상                          비교 질문은 답하지 않음
         ├─ BOM 에는 있고 데이터시트가 없음         USBLC6-4SC6-ES, BAT54W, 수동 소자 → 답하지 않음
         ├─ BOM 에 없는 품번                       답하지 않음
         └─ 부품이 없는 질문                       어느 문서를 볼지 정할 수 없어 답하지 않음
```

**검색 범위는 화면에서 문서를 켜고 꺼서 정한다.** 시연 화면 사이드바에 등록 문서가 체크박스로 있다.
켜진 문서가 여러 권이면 질문의 품번으로 한 권을 고르고, 한 권만 켜면 품번 없이 물어도 그 문서에서 찾는다
(변종은 보드에 쓴 BOM 품번 기준, 예: TPS2552DBVR). 꺼진 문서의 부품을 물으면 검색하지 않는다.

**여러 PDF 를 한 색인에 섞지 않는다.** 섞으면 IDF 와 점수 분포가 바뀌어 기준값이 의미를 잃고,
다른 부품의 공통 청크가 근거로 섞인다. 문서마다 색인을 따로 두고 문서를 먼저 고른다.

**품번 규칙은 문서마다 등록한다.** 제조사마다 규칙이 다르기 때문이다.

| 문서 | 변종을 가르는 것 | 변종이 아닌 꼬리 | 등록한 규칙 (캡처 = 변종 이름) |
|---|---|---|---|
| CH334/CH335 (WCH) | 접미사 한 글자 (U, R, Q ...) | 없음 | `(CH33[45][FHLPQRSU])` |
| TPS2552/53 (TI) | 끝자리 2/3 = EN 극성, `-1` = 래치오프 | DBV/DRV 패키지, R 릴 | `(TPS255[23](?:[-–]1)?)` |
| LMR33630 (TI) | A/B/C = 400 kHz / 1.4 MHz / 2.1 MHz | DDA/RNX 패키지 | `(LMR33630[ABC])` |
| TPS7A20 (TI) | 뒤 숫자 = 출력 전압 (33 = 3.3 V) | P 방전 기능, DBV | `(TPS7A20\d{2,3})` |
| LM66100 (TI) | 변종 1종 | DCK, R | `(LM66100)` |

처음 만든 CH334 전용 정규식(영문 2~5자 + 숫자 + 접미사)은 TI 품번을 읽지 못했다
(`TPS2552DBVR`, `LMR33630ADDAR` 추출 실패, `TPS2552-1` 의 `-1` 소실). 문서별 규칙으로 바꾸면서
CH334 에서 주변 부품(CH213K)과 패키지 코드(QFN16C)가 변종으로 잡히던 문제도 이 경로에서는 없다.

## 새 데이터시트 등록 절차

1. **대상 고르기.** `python tools/catalog_report.py` 를 돌려 `results/catalog_coverage.md` 의
   "품번은 있으나 데이터시트 미등록" 목록에서 고른다.
2. **PDF 넣기.** `data/datasheets/` 에 넣고 `data/catalog.json` 에 파일, 제목(리비전 포함), 제조사, 역할을 적는다.
3. **변종 규칙 쓰기.** 데이터시트의 주문 정보 표나 Device Comparison 표를 보고
   `variant_patterns`(캡처 그룹이 변종 이름)와 `family_patterns`(계열명)를 쓴다. 패키지와 포장 꼬리는
   변종 이름에 넣지 않는다.
4. **BOM 대응 확인.** `catalog_report.py` 를 다시 돌려 BOM 값이 의도한 문서와 변종으로 잡히는지 본다.
   (예: `LMR33630ADDAR` → 문서 lmr33630, 변종 LMR33630A)
5. **평가 질문 쓰기.** `tests/catalog_questions.json` 에 답이 있는 질문 3개 이상(변종을 가르는 질문 1개 포함),
   문서에 없는 질문 1개. `evidence_must` 에는 정답을 **데이터시트 원문 표현 그대로** 적는다.
   `python evaluate_catalog.py --verify` 로 그 표현이 원문 어느 쪽에 있는지 확인한다.
6. **측정.** `python evaluate_catalog.py`. 기준값은 바꾸지 않는다.
   - 필수: 문서 선택이 모두 맞고, 답하지 말아야 할 질문이 모두 차단될 것
   - 보고: 답 있는 질문 통과 수, 상위 5개 근거에 정답 문장이 있는 수 (못 미친 원인을 기록)
7. **못 미치면 이 순서로 고친다.**
   ① 용어표 보강 (`src/glossary.py`) → ② 변종 규칙 수정 → ③ 청킹 점검 →
   ④ 마지막에 기준값 재보정. 기준값은 전체 평가셋으로만 다시 정하고, 문서 하나를 맞추려고 바꾸지 않는다.
8. **회귀 확인.** `python -m unittest discover -s tests`, `python evaluate.py`(CH334 전수 검사),
   `python calibrate.py` 값이 그대로인지.

## modulino 에 적용한 결과 (2026.10.26)

등록 문서 5권: CH334/CH335, TPS2552/53, LMR33630, TPS7A20, LM66100. BOM 의 IC 6개 위치(U1, U2, U3, U5, U6, U7)가
품번 규칙만으로 자동 대응됐다. 평가 질문 29개 (답 있는 질문 19, 답하지 말아야 할 질문 10).
기준값은 CH334 평가셋으로 정한 2.5 / 0.67 을 그대로 썼다. **TI 문서 4권은 기준값을 정할 때 쓰지 않은 문서다.**

| 측정 | 문서 선택 | 답 있는 질문 통과 | 근거에 정답 문장 | 답하지 말 질문 차단 |
|---|---|---|---|---|
| 등록 직후 | 28/29 | 17/19 | 14/19 | 10/10 |
| 보강 후 | 29/29 | 19/19 | 15/19 | 10/10 |

등록 직후에 막힌 것과 고친 것
- `CH334U의 동작 전압(VDD33)은?` 이 두 부품 질문으로 잘못 분류됨. 핀 이름 VDD33 을 모르는 품번으로 셌다
  → 문서가 정해진 뒤에는 품번 모양이 뚜렷한 것(영문 3자 + 숫자 3자 이상)만 두 번째 부품으로 센다
- `LM66100의 최대 연속 전류는?` 이 근거 충분성에서 막힘. "최대", "연속" 이 용어표에 없었다 → 용어 2개 추가,
  TI 표기 IQ 를 "정지 전류" 의 동의어로 추가
- 같은 질문의 검색 결과가 실행마다 달랐다. 순위 질의에서 품번을 지울 때 계열명(TPS7A20)을 품번(TPS7A2033)보다
  먼저 지우면 "33" 이 남는데, 지우는 순서가 집합 순회 순서라 실행마다 바뀌었다 → 긴 것부터 지우도록 고침.
  CH334 는 질문마다 품번 문자열이 하나라 드러나지 않던 버그다. 위 표는 고친 뒤 다시 잰 값이다

답변까지 돌린 결과 (이 PC 의 로컬 모델 gemma3 4B): 답 있는 질문 19개 중 정답 11개.
- 값을 잘못 고름 2건: 절대최대값(-0.4~4.0 V)을 동작 전압으로(C1), 열저항을 온저항으로(M3)
- 근거가 있는데 거절 4건(T3, L4, P2, P3), 근거 밖 값 1건(P1), 근거에 정답이 없던 질문 1건(T5)
- U1(TPS2552) 극성 답은 정답 뒤에 “-1 변종은 활성 높음” 이라는 틀린 설명을 덧붙였는데, 문자열 채점은 정답으로 셌다
- 검색과 차단 단계는 결정적이고 기준을 지켰다. 병목은 4B 로컬 모델의 답변이다

보강 후에도 남은 것 (근거에 정답 문장이 없음 4건)
- TPS2552 동작 전압 범위, TPS2552-1 래치오프, LMR33630 최대 출력 전류, TPS7A2033 출력 노이즈.
  모두 1쪽 기능 목록에 한 줄로 요약된 값인데, 검색이 조건별로 나뉜 전기적 특성 표를 먼저 가져왔다.
  다음 단계는 기능 목록과 표 구조를 보존하는 파서다.
- 용어 보강은 양쪽으로 움직였다. "최대" 를 넣자 LMR33630 최대 출력 전류의 근거가 빠졌다.
  그래서 보강할 때마다 전체 평가셋을 다시 돌린다.

## 한계

- 비교 질문(두 부품, 두 변종)은 답하지 않는다. 한 번에 한 부품씩 묻는다
- 수동 소자는 BOM 값을 보여 주는 데서 멈춘다 (데이터시트가 없다)
- 기준값은 BM25 점수 분포에 기대고 있다. 이번 TI 4권에서는 그대로 통과했지만, 문서 길이나 문체가 크게
  다르면 경계 사례가 생긴다 (LM66100 최대 연속 전류는 1위 점수 2.28 로 기준 2.5 바로 아래였다)
- 평가 질문은 등록하는 사람이 쓴다. 독립성은 없고, 원문 표현을 함께 적어 검수할 수 있게 한 것까지다
