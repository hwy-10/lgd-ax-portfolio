## Note — 모호했던 것과 처리 방식

### Note 1 — 가격 출처 표기

| 기호 | 의미 |
| --- | --- |
| **V** | LCSC 제품 페이지에서 확인한 실제 단가 (품번 병기) |
| **E** | 추정. 동급 부품의 통상 LCSC 단가 |
| **P** | PCB 피처 — 구매 부품이 아님 (테스트포인트 패드, 납땜 브리지 동박) |

확인된 것은 9개(`LMR33630ADDAR` `TPS2552DBVR` `LM66100DCKR` `TPS7A2033PDBVR` `CH334U` `USB_A` `SMAJ15CA` `PJ-102AH` `DC-005`)이고 나머지는 추정입니다.

### Note 2 — 수량 할인 미반영

전부 **1개 단가**입니다. LCSC/JLCPCB에서 10~100개 발주 시 통상 **30~50 % 낮아집니다.** 특히 수동소자는 낙폭이 큽니다. 양산 원가는 이 표보다 낮게 나옵니다.

### Note 3 — 풋프린트 미지정 37개

`USB_HUB_CORE` 13개, `USB_HUB_PORT` 24개가 풋프린트 미지정 상태입니다. 이 부품들의 단가는 **값(Value)에서 패키지를 추정**해 산정했습니다. 풋프린트를 확정하면 재계산이 필요합니다 — 다만 대부분 0402/0603 수동소자라 총액 영향은 $0.05 미만입니다.

### Note 4 — `J7` 배럴잭 교체 (2026-08-23 적용)

원래 지정된 **CUI PJ-063AH**는 두 가지 문제가 있었습니다.

1. LCSC 실가 **$1.2130** — 교체 전 보드 원가 $5.093의 **24 %**
2. **LCSC 재고 0** (`C22434582`) — 발주 불가

#### PJ-102AH 채택 근거 — 데이터시트 대조 결과

CUI PJ-102AH 도면(REV A, 2005-11-17)과 KiCad `BarrelJack_CUI_PJ-102AH_Horizontal`을 직접 대조했습니다.

**플러그 호환성 변화 없음**: PJ-063AH·PJ-102AH 모두 센터핀 Ø2.0 mm / 5.5 mm 배럴로, 같은 12 V 어댑터를 씁니다.

**전류 여유**: 8 A → 5 A로 낮아졌지만, 12 V 입력 전류는 최대 약 **1.2 A**(5 V 2.5 A ÷ 효율 0.9 ÷ 12 V)이므로 4배 여유입니다.

#### 회로도 변경 내역

```
lib_id     Connector:Barrel_Jack_MountingPin  →  Connector:Barrel_Jack_Switch
Footprint  BarrelJack_CUI_PJ-063AH_Horizontal →  BarrelJack_CUI_PJ-102AH_Horizontal
Value      12V 3A                             →  12V 5A
MPN        PJ-063AH                           →  PJ-102AH
pin "MP"                                      →  pin "3"
삭제       MP → GND 배선 + 전용 GND 심볼
추가       no_connect @ (31.75, 52.07)   ← 핀 3
```

**3번 핀을 NC로 둔 이유**: PJ-063AH의 `MP`는 기계적 마운팅 핀이었지만 PJ-102AH의 3번은 **스위치 접점**입니다. 스위치가 플러그 미삽입 시 1번(팁)에 붙는 타입이면 GND에 묶었을 때 `+12V_IN`이 GND로 단락됩니다(소스가 없어 파괴되진 않지만 잘못된 결선). **어느 타입이든 NC는 무조건 안전**하고, 나중에 삽입 감지 용도로 쓸 여지도 남습니다.

#### Note 4-1 — ⚠ PCB 단계에서 확인할 것

**KiCad 풋프린트는 Ø1.6 원형 홀이지만 데이터시트는 1.00 × 1.60 슬롯입니다.** 원형 Ø1.6은 슬롯을 포함하므로 핀은 들어가지만 헐거워집니다. 배럴잭은 반복 삽입·발거 응력을 받으므로 **드릴을 1.00 × 1.60 장공으로 바꾸는 것을 권장**합니다.

또한 PJ-063AH에 있던 **전용 마운팅 핀 2개가 사라졌습니다.** 3개 THT 핀만으로 지지하므로, 케이스 고정이나 넉넉한 애뉼러링으로 보강하십시오.

#### DC-005를 채택하지 않은 이유

$0.1445로 **$0.459를 더 아낄 수 있지만 KiCad에 전용 풋프린트가 없습니다.** 후보가 두 개인데 홀 형태가 서로 호환되지 않습니다.

```
BarrelJack_Horizontal                 홀 1.0 × 3.0 슬롯  (평판 핀용)
BarrelJack_CUI_PJ-102AH_Horizontal    홀 Ø1.6 원형       (가는 핀용)
```

핀 **위치**는 6.0 mm + 4.7/3.0으로 동일하지만 **홀 형태**가 달라, 잘못 고르면 커넥터가 안 들어갑니다. LCSC가 데이터시트 자동 조회를 차단해 DC-005의 랜드 패턴을 확인하지 못했습니다.

> **DC-005로 더 내리려면**: LCSC `C381116` 페이지에서 데이터시트 PDF를 열어 PCB LAYOUT의 홀 치수를 확인하십시오. 1.00 × 1.60이면 지금 쓰는 `BarrelJack_CUI_PJ-102AH_Horizontal`을 **그대로 쓸 수 있고**, 회로도는 Footprint·MPN만 바꾸면 됩니다(심볼·결선 변경 불필요 — 둘 다 3핀 스위치형).

### Note 5 — ESP32-S3 DevKit 본체는 BOM에 없음

회로도에는 DevKit을 꽂는 **소켓 `J1`·`J2`만** 있습니다. 모듈 자체는 심볼이 없어 넷리스트에 잡히지 않습니다.

MCU 모듈의 실제 비용은 **$0.415 + DevKit 약 $7~8 = 약 $7.4~8.4**입니다. 보드에서 압도적으로 비싼 항목입니다.

> 정품 ESP32-S3-DevKitC-1은 Micro-USB입니다(USB-C는 클론). 클론은 $4~5까지 내려가지만 LDO·쇼트키 구성이 달라 [POWER 설계 전제](VBUS_bulk_capacitor_design.md)가 흔들릴 수 있습니다.

### Note 6 — `U7` LDO 계열은 기능상 불필요

`+3V3` 레일의 실부하는 `R37`(벅 PG 풀업) 하나뿐이고, LMR33630 데이터시트가 PG를 `V_OUT`에 직접 올려도 된다고 명시합니다(PG 절대최대 22 V).

| 삭제 대상 | 절감 |
| --- | --- |
| `U7` TPS7A2033PDBVR | $0.0686 |
| `C41`,`C42`,`C43`,`C44` | $0.0300 |
| **합계** | **$0.0986** |

금액은 작지만 **부품 5개, SOT-23-5 1개분 면적**이 줄어듭니다. `R37`의 풀업 대상만 `+3V3` → `+5V`로 바꾸면 됩니다.

### Note 7 — LED 레퍼런스가 비표준

`PORT1`~`PORT5`는 부품 종류가 아니라 용도를 이름으로 쓴 것입니다. KiCad 표준은 `D` 또는 `DS`입니다. 어노테이션 정리 시 `DS1`~`DS5`가 되며, 포트 번호는 실크로 표기해야 합니다. **원가에는 영향 없습니다.**

### Note 8 — 미포함 항목

이 표는 **부품 원가만**입니다. 다음은 포함되지 않았습니다.

- PCB 제조비 (4레이어 필요 — 벅 발열 + USB 차동쌍 아래 연속 GND 플레인)
- 조립·실장비 (SMT 스텐실, 리플로)
- 케이스·나사·라벨
- 12 V 어댑터
- 불량률·스크랩

### Note 9 — `C1`~`C4` MPN 미확정

`47uF/16V POLY`로만 지정돼 있고 구체 품번이 없습니다. $0.20은 알루미늄 폴리머 통상가 추정입니다. 발주 전 확정 필요 — [VBUS_bulk_capacitor_design.md §3](VBUS_bulk_capacitor_design.md) 참조.

### Note 11 — USB 데이터선 ESD (`U4`·`U8`)

USB 2.0 규격 요구사항은 아니지만, 외부 노출되는 USB-A 4포트의 IEC 61000-4-2 내성 확보를 위해 추가했습니다.

| | |

| 선정품 | **USBLC6-4SC6-ES** (ElecSuper), LCSC **`C5180279`** |
| 수량 / 단가 | 2개 × $0.0198 = **$0.0396** |

선정 경위: SN75240($1.270) → USBLC6-4SC6 ST 정품($0.203) → **ElecSuper($0.040)**. **97 % 절감**.

**전체 선정 근거·후보 전수 조사·정정 이력·ESD 건 시험 판정 기준은 [ESD_protection_design.md](ESD_protection_design.md)** 에 있습니다.

> ⚠️ ESD 소자는 ERC·통전·열거 시험으로 검증되지 않습니다. **IEC 61000-4-2 접촉 8 kV 건 시험이 유일한 판정 수단**입니다.

### Note 10 — 모듈 경계는 시트 경계와 동일

`USB_HUB_CORE`와 `USB_HUB_PORT` 두 시트를 **USB HUB 모듈**로 합쳤습니다. 허브 컨트롤러(CH334U)와 포트 보호·커넥터는 기능적으로 분리 불가하기 때문입니다. 나머지는 시트 = 모듈로 1:1 대응합니다.

## 참고 — $2 상한 관련

USB HUB 모듈은 ESD 포함 **$1.911**로 **$2 이내**입니다. → **Note 11** 다만 이는 **부품 원가만**이며 PCB·조립·케이스는 빠져 있습니다. 상한이 "부품만"인지 "완성 모듈"인지 확인이 필요합니다.

전체 보드 기준으로는 DevKit($7~8)이 지배적이라, 어떤 정의로도 $2 안에 들어오지 않습니다.

### Note 12 — `C46`~`C49` 드룹 완화 예비 패드 (2026-08-23 추가)

`C1`~`C4`에 병렬로 놓이는 **미실장(DNP) 예비 자리**입니다. 원가 $0.

시뮬레이션상 USB 장치 핫플러그 드룹이 **430 mV로 규격 한도 330 mV를 초과**하는데, 이 값은 장치측 인러시 제한이 전혀 없다고 가정한 규격 최악 모델이라 실제로는 통과할 수도 있습니다. 그런데 보드가 없으니 실측이 불가능합니다.

```
실장 시   포트 국부 용량 94 -> 188 µF,  드룹 430 -> 253 mV  (합격)
추가 원가  4 × $0.20 = $0.80   -> USB HUB 모듈이 $2.71 이 되어 $2 상한 초과
```

**검증 V5-1 실측이 330 mV를 넘을 때만 실장하십시오.** 실장 후에는 V6(포트 단락)과 V3-2(기동 전류)를 재측정해야 합니다. 상세는 [검증 문서 §7-B](../plane/modulino_hub_ver1.0.md).

### Note 13 — `C28`~`C31`,`C34` 1206 → 1210 (2026-08-23 적용)

**풋프린트만 1210으로 바꾸고 부품은 1206으로 시작합니다.**

```
1206  3.2 × 1.6 mm
1210  3.2 × 2.5 mm     길이·단자 간격 동일 -> 1210 랜드에 1206 이 그대로 올라간다
```

이렇게 해두면 **검증 V4-4(DC 바이어스 인가 실효 용량 측정) 결과를 보고 리스핀 없이 부품만 교체**할 수 있습니다. 1206으로 그렸다면 1210이 안 올라가 리스핀이 필요했을 것입니다.

| 구성 | 정격합 | 바이어스 후 | −20 % 후 | TI 요구 52 µF |
| --- | --- | --- | --- | --- |
| 1206 ×5 | 110 µF | 60.5 µF | **48.4 µF** | ⚠ 미달 |
| 1210 ×5 | 110 µF | 82.5 µF | 66.0 µF | OK |

> 위 표의 단가 $0.1613은 **1210 실장 시** 값입니다(Samsung `CL32B226KOJNNNE`, LCSC `C55530`). 1206으로 시작하면 $0.1105(`C90146`)이고 POWER 모듈은 $2.579입니다.

### Note 14 — 기존 1206 단가 추정값 정정

BOM 초판의 `22uF/16V 1206 = $0.0400`은 **추정치("E")였고 실가와 2.8배 차이**가 났습니다.

```
추정  $0.0400
실가  $0.1105   Samsung CL31A226KOHNNNE (LCSC C90146)
```

다른 "E" 표기 항목들도 같은 수준의 오차를 가질 수 있습니다. **발주 전 전 항목 실가 재조회가 필요합니다.**

### Note 15 — 풋프린트 손납땜 사양 (2026-08-23)
